# 📚 FOSS Forex Resources & Strategy Map

## 📂 Open Source Trading Systems
1. **Freqtrade**: Best-in-class crypto/forex bot (Python).
2. **Lean (QuantConnect)**: Institutional-grade engine (C#).
3. **Jesse**: Advanced crypto/forex trading framework (Python).
4. **Hummingbot**: High-frequency market making (Python/C++).

## 📊 Core Strategies (FOSS Implemented in AAT)
- **SMC (Smart Money Concepts)**: Institutional liquidity sweeps and Order Block detection.
- **VSA (Volume Spread Analysis)**: Tom Williams methodology for effort vs result.
- **Donchian Breakout**: Trend following via price extremes.
- **ICT Killzones**: Session-based liquidity sweeps (NY Open).
- **Supertrend**: Volatility-adjusted trend detection.
